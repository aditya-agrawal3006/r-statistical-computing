## Format and tools

These are **PDF exports of R Notebook / R Markdown analyses**. Each report contains selected R code, generated tables, visualizations, and written interpretations. The editable R notebook source files and the original input datasets are not included, so these are presented as **results to review**, not as independently rerunnable projects.

**Tools used in the reports:** R, tidyverse, ggplot2, simulation functions, data frames, and statistical visualization.

## Project background

Prepared as coursework at the **University of Maryland**. The reports represent student analyses; assignment prompts or starter examples may have been provided as part of the coursework. Original report PDFs have been retained without editing their contents.
